# Reset-kernel USB promotion: independent artifact review

The rebuilt USB glue and corrected initramfs have no source, module-linkage or archive-content blocker. This review performed no hardware access, module load/unload, sysfs operation, installation or reboot. Root owns the separate native USB trial and checks storage/network ownership before normal teardown.

The external source is byte-identical to the previously promoted fixed-host role provider, SHA-256 `7ca78866b27aa670134ded04820c26b7cabfb17640c410ee5cf3b307e0aa5b0c`. Its only difference from the reset-kernel source is the existing `experimental-t6040-fixed-host-role-switch.patch`. The fixed-host init lock ends before role registration; only T6040 gains registration, device-role rejection stays intact, and registration failure unwinds core initialization. All six copied DWC3 headers match the reset-kernel tree. The Makefile selects only the external glue module; the clean saved W=1 build uses the reset tree.

The new module SHA-256 is `6491446266d7ab6ba4ec3b3c0229d609b2b465b73ab065a0834d66265babdd98`, GNU build ID `39d100615339cf32659ae189c63dafad540753ab`, with AArch64 ELF and vermagic `7.1.13-m4rch-gpu-reset SMP preempt mod_unload aarch64`. All 39 undefined symbols resolve in the reset kernel's Module.symvers: 30 kernel exports and 9 DWC3 exports. CONFIG_MODVERSIONS is disabled, so this review makes no symbol-CRC claim. No forced version loading is needed.

The corrected initramfs SHA-256 is `86dec6ff3b9a4aef1678632d1fcf2371f01e9755c3f39ec15a42fc0b9485d01d`. An independent in-memory newc/gzip parser compared 4 early and 294 main members, excluding the two trailer records. The member inventories and all mode/body pairs are identical to the installed reset-kernel archive except the exact reviewed DWC3 Apple module. Init, root geometry configuration, buildconfig, DWC3 core, NVMe and SART payloads remain byte-identical. The early `modprobe dwc3_apple` still precedes switch_root. The parser executed no archive member.

These checks establish the bounded USB promotion's contents and link compatibility. They do not establish native USB reload success, PD binding, cable behavior, GPU reset coverage, recovery or DMA retirement. The kernel Image/API and frozen GPU owner/graph remain separately qualified identities; this external USB promotion does not amend their original receipts.
