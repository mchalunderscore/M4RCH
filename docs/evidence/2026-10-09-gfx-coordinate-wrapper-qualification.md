# Paired coordination wrapper qualification — 2026-10-09

The actual generated cold and resident wrappers pass **353 offline Python cases**, including 114 reused admission/durable-intent cases and 49 executions of the actual transformed cold `main()`. All external operations in those executions were intercepted. No module, native sampler, PM operation, MMIO or firmware command ran.

The [bound JSON receipt](2026-10-09-gfx-coordinate-wrapper-qualification.json) records exact thin-runner, contract, fixture, inherited-source and test hashes, plus generated-code hashes. The complete normalized mock traces are in ignored `out/gfx-native-coordinate/wrapper-qualification.json`, whose hash is also bound. Tests are [test-coordinate-runners.py](../../experiments/t6040-gpu/gfx-native-coordinate-trial/test-coordinate-runners.py).

The suite exercises compilation of both actual transforms and their frozen-base SHA/unique-insertion guards. The inherited qualifier is itself SHA-bound, then changed only to load the paired contract/runners and aggregate its cases. It verifies exact cold parameters (`run_gate=2`, `observe_ms=5000`, `resident_session=1`), typed-command admission, packet-free stop before one OFF intent, durable intent before a simulated sysfs write, write/open/interruption failures, and no second OFF, cleanup, restart or submission admission.

All 12 native ADT pins are tested independently for changed bytes, missing properties and wrong lengths. Each byte mutation also runs through actual cold `main()` and refuses before cold owner loading. The normalized Linux fixture has 312 nodes and is reconstructed entirely in a temporary directory. Changed/missing selected resource properties, a new available PMP alias, added translation/address properties, malformed cell/tuple shapes, modified fixture hashes and the OF `device_type` bus selector refuse. Actual main refuses a changed Linux layout before any native helper capture or load. The selected-property snapshot intentionally ignores properties that do not affect this resource-layout guard.

Retained startup qualification requires one unambiguous record, a successful load, a positive module reference count, exact negative result/retention fields, and explicit absence of mapping/root publication. The suite rejects duplicate fields, numeric prefixes with trailing garbage, missing/nonboolean report observations, ambiguous logs, a wrong loaded GNU build note and a zero reference count. Known malformed records may raise after synced cold-load intent; those tested failures make no further graph read, powered sampler, cleanup or retry.

Successful startup admission requires exactly one complete ON observation and one complete post-active ON owner record, raw ACK status bit1, the requested bit13, bounded unsigned 64-bit words, completed votes, retained regions/mappings, root publication and mapped-page evidence. Wrong ACK bit54 alone, missing/contradictory records, all-ones/signed/oversized words, failed load and zero reference count refuse. Qualified resident and diagnostic records reach the inherited observation branch. Missing records or an absent module after cold-load intent save a durable unknown outcome with no commands, cleanup or retry. Every retained/unknown exit was tested with post-load graph reads and powered sampling forbidden.

Independent review found the parser, positive-admission and missing `device_type` gaps above; the parent fixed the actual sources before this final qualification. No remaining blocking defect was found within the frozen-owner assumptions. Historical sources were preserved.

This qualifies wrapper control flow and metadata identity. The main fixture preserves the lifetime/contract checks but elides optional receive-service decoding and joined-owned snapshot decoding; those inherited decoders are not requalified. The GNU note is a synthetic ELF fixture, not the future loaded candidate. Linux DT equality does not establish ownership, native runtime policy or hardware readiness: the adapter's C alias scan and resource claims remain authoritative. Canonical paired receipts omit legacy scope keys and are refused by old runners; the frozen legacy validator can still accept an artificially hand-mixed old/new receipt, while both paired runners reject every tested mixed receipt.

Neither these results nor the [pure-core qualification](2026-10-09-gfx-coordinate-core-qualification.md) establish hardware PMP/PMC equivalence, successful OFF, firmware cessation, DMA retirement, backing release, restart or rendering. The frozen live OFF failure is unchanged.
